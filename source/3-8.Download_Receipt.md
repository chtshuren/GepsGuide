電子領標憑證檔（副檔名為 .tkn）下載完成後，預設將儲存於系統之使用者下載目錄中。其標準檔案路徑如下：
C:\Users\<使用者帳號>\Downloads\<檔名>.tkn
**注意：請將 <使用者帳號> 替換為您登入 Windows 系統之實際帳戶名稱。**


Upon completion of the download, the electronic tender receipt certificate (file extension .tkn) will be saved by default in your system's User Downloads folder. The standard file path is as follows:
C:\Users\<Username>\Downloads\<Filename>.tkn
**Note: Please replace <Username> with your actual Windows account name.**

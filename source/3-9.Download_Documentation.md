For first-time users, please download and install the Electronic Tendering Application before downloading the tender documents. Once the application has been installed, you may proceed with the document download. Users who have already installed the application may download the tender documents directly.
**Note: This application is only supported on Windows systems. It will automatically launch and check for updates when the computer is turned on. If an update is available, the user will be prompted to update the application.**
